# Пакет 07 · Keyset-пагинация

**Цель:** заменить offset-пагинацию на курсорную и измерить выигрыш на 100k строк.

**Ветка:** `packet/07-keyset` · **Время:** 4–6 ч

## Теория (1–2 ч)

- Почему `OFFSET 10000` читает и выбрасывает 10 000 строк.
- Keyset: `WHERE (published_at, id) < ($1, $2) ORDER BY published_at DESC, id DESC LIMIT n`.
- Составной индекс под сортировку: `@@index([publishedAt, id])` — порядок колонок важен.

## Задачи

- [ ] 1. В `QueryVacanciesDto` добавить `cursor?: string` (`base64(publishedAt|id)`), в ответ — `nextCursor`.
- [ ] 2. Реализовать через Prisma `cursor: { id }` + `skip: 1`, либо `$queryRaw` для честного keyset.
- [ ] 3. Добавить составной индекс и проверить `EXPLAIN ANALYZE`: `Index Scan` вместо `Seq Scan` + `Sort`.
- [ ] 4. Замерить: `OFFSET 10000` vs keyset на странице 500. Записать цифры в `03-notes.md`.
- [ ] 5. Тест: два подряд запроса не возвращают пересекающихся `id`.
