# Пакет 10 · Деплой и портфолио

**Цель:** сервис доступен по внешнему адресу, а репозиторий читается как работа
инженера, а не как учебная песочница.

**Ветка:** `packet/10-deploy` · **Время:** 6–8 ч

## Задачи

- [ ] 1. **VPS**: Docker + compose, `.env` на сервере (не в git), `docker compose up -d`.
- [ ] 2. **Nginx** как reverse proxy: `server_name`, `proxy_pass`, HTTPS через `certbot`.
- [ ] 3. **CI**: `.github/workflows/ci.yml` уже есть — добавить шаг деплоя по тегу или ручному запуску.
- [ ] 4. **README репозитория** для читателя: что за сервис, схема БД (Mermaid), как запустить, примеры `curl`, скриншот Swagger.
- [ ] 5. **`docs/decisions.md`**: 5–7 решений с обоснованием (Prisma vs TypeORM, keyset vs offset, RepeatableRead, Redis, почему не микросервисы).
- [ ] 6. **Бейджи** CI и ссылка на живой API в шапке README.

## Критерии приёмки

- [ ] `curl https://<домен>/api/health` отвечает снаружи
- [ ] README понятен человеку, который не видел проект
- [ ] В резюме можно вставить ссылку на репозиторий и живой API
- [ ] Секретов в истории git нет (`git log -p | grep -i password` — пусто)
